m5-uarch

Instruction latency and throughput, and core structure sizes, measured on Apple Silicon without root. Every number comes from the kernel's per-thread cycle and instruction counters; nothing here is taken from documentation.

How to read this page

  • Latency is in cycles, from one input operand to the output, measured in a dependency chain. When inputs differ, the cell shows the range; open the row for each one. A value near 0 means the instruction was removed at rename.
  • Throughput is how many independent instances complete per cycle in a long stream of that one instruction.
  • Values are the median of several runs. Non-integer latencies are real averages, not rounding noise: some operations alternate between two latencies.
  • rt marks a round trip: the chain had to return to its starting register file through a second instruction (named in the row) whose share cannot be separated by timing.
  • Without root there are no event counters. Everything except cycles and retired instructions is inferred from timing experiments; open a structure row to see the curve it was read from.
